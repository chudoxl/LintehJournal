## What Was Done

### Task 1 — Lint disable in `composeApp/build.gradle.kts`

Added a `lint { disable += "NullSafeMutableLiveData" }` block inside the
existing `android { ... }` scope (after `testOptions { ... }`), with a
9-line bilingual comment explaining:

- **Why disable** — AGP 8.7.3 bundles `NonNullableMutableLiveDataDetector`
  compiled against Kotlin 2.0.x lint-analysis API; on Kotlin 2.2.20 it
  throws `IncompatibleClassChangeError` at `lintAnalyzeDebug`.
- **Why safe** — Detector targets `androidx.lifecycle.MutableLiveData`,
  zero usages in this Compose Multiplatform / ViewModel KMP codebase
  (`grep -rn 'MutableLiveData' --include='*.kt'` returns nothing).
- **Recommended workaround** — AGP's lint output itself prints the
  `disable += "..."` suggestion.
- **Revisit condition** — When AGP 8.8+ rebuilds bundled detectors
  against Kotlin 2.2 lint-analysis API.
