After developer signals "captures committed" in Task 1, run the validation suite to confirm fixtures meet the contract Plan 06 will rely on.

This task is fully automated — no human input. It runs:
1. **Existence check**: all 12 expected file paths exist
2. **JSON validity**: each file parses as valid JSON via `python3 -m json.tool`
3. **HAR schema**: each file has `log.entries[]` array (HAR 1.2 minimum)
4. **Non-empty entries**: each fixture has at least 1 entry with a non-empty response body
5. **Canary script**: `tests/sanitize-har-canary.sh` exits 0 (no PII leak)
6. **Cookie redaction sanity**: any cookie value in fixtures is composed of 'X' characters only (sanitize-har.py invariant)

Implementation: this task does not modify files; it runs verification commands. If any check fails, report which file/check failed so the developer can re-capture or extend sanitize-rules.yaml.

Run these commands sequentially, reporting per-file status:

```bash
set -euo pipefail

echo "=== Existence ==="
for ACCT in A B; do
  for ENDP in login grades schedule homework attendance messages; do
    F="fixtures/sanitized/account-${ACCT}/${ENDP}.har"
    test -f "$F" || { echo "MISSING: $F"; exit 1; }
    echo "OK exists: $F"
  done
done

echo "=== JSON validity ==="
find fixtures/sanitized -type f -name '*.har' | while read F; do
  python3 -m json.tool "$F" > /dev/null || { echo "INVALID JSON: $F"; exit 1; }
done

echo "=== HAR schema (log.entries presence) ==="
find fixtures/sanitized -type f -name '*.har' | while read F; do
  python3 -c "
import json, sys
with open('$F') as f: h = json.load(f)
e = h.get('log', {}).get('entries', [])
if not isinstance(e, list) or len(e) == 0:
    sys.exit('NO ENTRIES: $F')
print('OK entries=' + str(len(e)) + ': $F')
"
done

echo "=== Cookie value sanitization (must be all 'X') ==="
find fixtures/sanitized -type f -name '*.har' | while read F; do
  python3 -c "
import json, sys
with open('$F') as f: h = json.load(f)
for e in h.get('log', {}).get('entries', []):
    for k in ['request', 'response']:
        for c in e.get(k, {}).get('cookies', []):
            v = c.get('value', '')
            if v and not all(ch == 'X' for ch in v):
                sys.exit('UNSANITIZED COOKIE: ' + c.get('name', '?') + '=' + v[:20] + '... in $F')
print('OK cookies sanitized: $F')
"
done

echo "=== PII canary ==="
bash tests/sanitize-har-canary.sh

echo "=== ALL CHECKS PASSED ==="
```

If any step fails, the orchestrator presents the failure to the developer, who returns to Task 1 (capture/sanitize specific files) and re-runs Task 2.
