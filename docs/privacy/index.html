Политика конфиденциальности

«ЛИнТех Дневник» — неофициальный мобильный клиент для электронного дневника ИАС «АВЕРС: Электронный Классный Журнал» школы №28 г. Кирова.

Замечание для версии 0.1.0: текущая сборка является технической foundation-версией без логин-flow, без локальной БД, без cookies сессии и без экрана настроек. Разделы ниже описывают целевую модель данных v1; по мере подключения функций (Phase 2 — auth, Phase 3 — кэш БД, Phase 4 — Settings + logout) этот документ будет обновляться, история — git.

Что мы НЕ делаем

  • Мы не отправляем ваши данные третьим лицам.
  • Мы не используем рекламу и трекеры.
  • Мы не собираем аналитику использования.
  • Мы не имеем доступа к вашим учётным данным или оценкам — у нас нет собственного сервера.

Что будет храниться на вашем устройстве (целевая модель v1)

Когда соответствующие функции будут реализованы, все данные приложения будут храниться локально на устройстве:

  • Логин и пароль АВЕРС — в защищённом хранилище ОС (iOS Keychain, Android Keystore) — Phase 2
  • Кэш оценок, расписания, домашних заданий — в зашифрованной локальной базе — Phase 3
  • Cookies сессии АВЕРС — также локально — Phase 2

В версии 0.1.0 ничего из перечисленного на устройстве пока не сохраняется (нет логин-flow и БД).

С какими сервисами мы общаемся

Приложение обменивается данными только с одним адресом: journal.school28-kirov.ru — официальный сайт ИАС АВЕРС школы №28.

HTTPS-соединение обязательно. Сертификат проверяется системой устройства.

Перечень обрабатываемых ПДн

  • Логин (email или телефон) — для входа в АВЕРС
  • Пароль — для входа в АВЕРС, хранится локально, не покидает устройство кроме запроса к АВЕРС
  • ФИО ученика — отдаётся сервером АВЕРС в ответ на ваш запрос
  • Оценки, расписание, домашние задания, посещаемость, сообщения от учителей — данные, которые вы получаете из АВЕРС

Удаление данных

В целевой v1: кнопка «Выйти» в настройках приложения удалит все локальные данные аккаунта (логин/пароль из Keychain/Keystore, кэш базы, cookies). После выхода никаких данных приложения на устройстве не останется. Эта функция появится в Phase 4 вместе с экраном настроек.

В версии 0.1.0 удалять нечего — приложение пока ничего на устройстве не сохраняет; при необходимости можно удалить приложение стандартным способом ОС.

Связь с разработчиком

Приложение разработано независимым разработчиком для семейного использования. Не аффилировано с ИИЦ «АВЕРС», школой №28 или Минобром Кировской области.
